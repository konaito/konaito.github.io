macOS utility · v0.1.1

Codex
Notification Bridge

作業中のCodexセッションを一覧表示し、入力内容と直近の会話・作業状態から送信先を予測して、選択したタスクへメッセージを挿入するElectronアプリです。

Apple Silicon版をダウンロード（121MB）
macOS arm64 · Electron 44.3.0 · Developer ID署名済み・Apple公証済み · Release details

インストール

  1. ZIPをダウンロードして展開します。
  2. Codex Notification Bridge.app をApplicationsへ移動します。
  3. 初回に警告が出た場合は、アプリを右クリックして「開く」を選びます。

必要環境

  • Apple Silicon搭載Mac（Mシリーズ）
  • ログイン済みの codex CLI
  • Codexの作業中セッションにアクセスできる環境

アプリはDeveloper IDで署名し、Appleの公証を通しています。ソースコードは公開リポジトリで確認できます。
